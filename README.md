# 📊 DecodeLabs Project 4: Data Visualization

**By Dua** | DecodeLabs Data Analytics Internship, Batch 2026

A one-page dashboard that turns my Project 3 SQL results into clear, honest charts.
Dataset: 1,200 orders (`DecodeLabs_Week2_EDA_Dua.xlsx`).

## The story in one line
**Revenue is spread evenly across products, but 41% of orders never complete.**

## Key insights
- 🪑 **Products:** Chair and Printer lead at 15.5% of revenue each, but no product dominates.
- 📱 **Channels:** Instagram is the top channel, with $275K from 259 orders.
- ⚠️ **Order status:** only 19% of orders are Delivered, while 41% are Cancelled or Returned.
- 🏷️ **Coupons:** average order value stays within $35 across all coupon groups, so coupons do not change basket size.

## Charts
Bar charts (product, referral source), a 3-slice donut (order status) and a column chart (coupons).
Every chart starts at zero, has direct labels, uses one blue accent for the key insight, and carries an action title.

## How to view
Download `decodelabs_project4_dashboard.html` and open it in Chrome.
